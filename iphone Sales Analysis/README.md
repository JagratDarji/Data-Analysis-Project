📁 Project Overview

This project analyzes iPhone sales performance over multiple years using Python.
The goal is to explore trends, pricing changes, demand patterns, and identify key insights for business decision-making.

🚀 Tech Stack Used

Python

Pandas

NumPy

Matplotlib

Seaborn

Jupyter Notebook
